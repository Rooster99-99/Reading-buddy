# Reading-buddy
Reading assistance for 2nd to 5th grade students. 
Home screen: four neon grade cards (Grade 2, 3, 4, 5) over a grid and city skyline. Each card has a progress bar, and each grade keeps its own progress. Her stars carry across all grades.
Home button: a glowing house icon in the top-left corner of the practice screen goes back to the grade menu.
Grown-up setup: hold the small SETUP button on the home screen for 2 seconds. It's a hold so she won't open it by accident.
Swap red/blue: try this first to fix your red color issue. It's saved, so you only do it once.
Invert screen: fixes a "photo negative" look if a board ever has one.
Redo touch setup
Reset all progress
